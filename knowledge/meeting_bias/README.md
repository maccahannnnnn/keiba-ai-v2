# MeetingBias Knowledge Template

This directory is reserved for KeibaAI Ver0.94 MeetingBias knowledge.

MeetingBias is separate from TrackBias.

- MeetingBias: meeting stage, course rotation, turf wear, meeting progression.
- TrackBias: same-day inside/outside and front/closer tendency.

Planned layout:

```text
knowledge/meeting_bias/
  meeting_bias_template.json
  sapporo.json
  hakodate.json
  fukushima.json
  niigata.json
  tokyo.json
  nakayama.json
  chukyo.json
  kyoto.json
  hanshin.json
  kokura.json
```

Ver0.94 only provides the template.  No automatic inference, learning, scoring,
or evaluator connection is active.
